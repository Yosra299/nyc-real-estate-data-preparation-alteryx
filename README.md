# NYC Real Estate Data Preparation & Analysis with Alteryx

A hands-on **data preparation and ETL project** developed using **Alteryx Designer**, focused on transforming raw data into clean, structured, and analysis-ready datasets.

## 🛠️ Technologies & Tools

- **Alteryx Designer**
- Data Cleaning & Preparation
- ETL & Workflow Automation
- Data Transformation
- Data Joining & Blending
- Data Aggregation
- Data Validation

## 🔍 What I Worked On

- Imported and profiled data from multiple sources
- Cleaned and standardized raw datasets
- Handled missing values and data quality issues
- Filtered and transformed data based on business requirements
- Joined and blended datasets from different sources
- Applied aggregations and calculations
- Built reusable **Alteryx workflows** to automate data preparation
- Produced structured datasets ready for analysis and reporting
