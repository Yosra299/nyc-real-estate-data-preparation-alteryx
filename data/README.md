# Data

The datasets used in this project are **not included in this repository** because they were provided through a licensed DataCamp course and are subject to the course's usage and distribution restrictions.

The data was used locally to demonstrate practical skills in:

- Data cleaning and preprocessing
- Data profiling and quality checks
- Data transformation
- Data integration and joining
- Data aggregation
- ETL workflow development
- Preparing data for analysis and reporting

The **Alteryx workflows and project documentation** are provided separately to demonstrate the data processing approach and technical skills developed during the project.
